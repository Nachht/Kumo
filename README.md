## 📖 Descripción

**Kumo** es una tienda online enfocada en ofrecer productos relacionados con el mundo del anime.

El proyecto busca brindar una experiencia moderna, intuitiva y atractiva para que los usuarios puedan explorar diferentes categorías de productos, descubrir novedades y realizar compras de manera sencilla.

Actualmente el proyecto cuenta con una interfaz moderna y responsive, diseñada para ofrecer una experiencia agradable tanto en computadores como en dispositivos móviles.

---

## ✨ Características

- 🎌 Diseño moderno inspirado en el mundo del anime.
- 📱 Diseño completamente responsive.
- 🛒 Catálogo de productos.
- 🎠 Carrusel interactivo en la página principal.
- 🏷️ Secciones organizadas por categorías.
- 🔍 Navegación intuitiva.
- 🎨 Interfaz con animaciones y efectos visuales.
- ⚡ Código organizado para facilitar el mantenimiento.

## 🚀 Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/usuario/kumo.git
```

2. Entrar al proyecto

```bash
cd kumo
```

3. Abrir el proyecto con Visual Studio Code.

4. Ejecutar mediante **Live Server** o cualquier servidor local.
